# VELOOP Rewards – Frontend Development

A modern, responsive rewards platform UI designed to showcase different reward-based features through interactive and visually engaging banners.

## About the Project

VELOOP Rewards is a frontend development project created as part of the **VELOOP Frontend Development Task**.

The objective was to build a professional, user-friendly rewards platform interface that presents multiple reward-related services in a clear, attractive, and interactive way.

The application includes five feature-focused sections designed to help users understand different reward opportunities and available redemption options.

## Project Features

### 1. Refer & Earn
- Encourages users to invite friends to the platform.
- Demonstrates a referral-based reward experience.
- Includes an interactive referral interface.

### 2. Swap Center
- Represents a platform for swapping supported reward balances or currencies.
- Displays a swap-style interface with balance information.
- Demonstrates the conversion experience.

### 3. Bonus VEs
- Highlights additional reward opportunities through eligible campaigns and promotions.
- Uses reward-focused visuals and interactive elements.

### 4. Captcha Tasks
- Demonstrates a captcha-based task verification workflow.
- Includes an interactive verification experience.
- Represents the flow: Task → Verification → Completion → Reward.

### 5. Exchange Center
- Showcases potential reward redemption options.
- Includes digital wallet, gift card, and other reward option interfaces.
- Demonstrates the reward selection experience.

## Project Use Cases

The interface demonstrates how a rewards platform can present:

- Referral-based reward programs.
- Reward balance swapping experiences.
- Promotional bonus opportunities.
- Captcha-based task verification.
- Reward redemption and exchange options.

**Note:** This is a frontend demonstration project. Actual authentication, payment processing, reward transactions, referral tracking, and backend integrations are not implemented.

## Installation and Setup

### Prerequisites
- Node.js
- npm
- Git

### Clone the Repository

```bash
git clone https://github.com/ranjitiwale/veloop-rewards.git
```

### Navigate to Project

```bash
cd veloop-rewards
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

### Production Build

```bash
npm run build
```
